# 初始管理员部署说明

应用首次启动且数据库中不存在任何管理员时，可通过环境变量创建初始管理员。

## 环境变量

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `ADMIN_BOOTSTRAP_ENABLED` | 否 | 默认 `true`；仅测试环境应显式关闭 |
| `ADMIN_BOOTSTRAP_USERNAME` | 管理员数量为 0 时必填 | 初始管理员用户名 |
| `ADMIN_BOOTSTRAP_EMAIL` | 管理员数量为 0 时必填 | 初始管理员邮箱 |
| `ADMIN_BOOTSTRAP_PASSWORD` | 管理员数量为 0 时必填 | 初始管理员密码，仅保存在部署 Secret/环境变量中 |

密码不得写入 Git、`.env.example`、迁移、日志、异常或监控标签。应用使用 BCrypt 保存密码摘要。

## 启动行为

1. 数据库迁移完成后初始化。
2. 锁定 `user_role_change_guard`。
3. 如果已经存在管理员，忽略所有 bootstrap 配置。
4. 如果没有管理员且配置缺失，启动失败。
5. 如果用户名或邮箱已被普通用户占用，启动失败，不静默提权。
6. 只创建一个 `ADMIN` 用户，`token_version` 为 `0`。
7. 日志只记录创建成功和内部用户 ID，不记录密码或邮箱。

多实例同时启动时，数据库 guard 锁保证只创建一个管理员。

## 部署后检查

- 确认数据库中管理员数量为预期值。
- 使用初始账号登录，通过管理员角色选择完成首次认证。
- 立即修改初始密码。
- 从部署环境中删除不再需要的 bootstrap 密码。
